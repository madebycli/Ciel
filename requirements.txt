# far too slow to speak in real time.
#

#   pip install -r requirements.txt
#

# --- Transparent desktop overlay (overlay_window.py) -------------------
# The overlay runs as its own process on Qt, NOT on pywebview. That is not
# a preference: pywebview hosts WebView2 in windowed mode, which renders
# into a child HWND, and per-pixel alpha needs a composited top-level
# window. Seven approaches were measured against a coloured backdrop and
# every one came back opaque. Qt's WA_TranslucentBackground does work, and
# QWebEngineView is the same Chromium engine, so the Three.js scene is
# unchanged - only the window hosting it differs.
#
# *** DO NOT pip install PySide6 into this environment. ***
#
# The overlay needs PySide6 6.4.3, and 6.4.3 has no Python 3.14 build.
# It lives in its own Python 3.11 virtualenv, .overlay-venv, which
# run_hud.py launches the overlay process under. Only the overlay moves;
# the app keeps running on 3.14 with torch and F5-TTS untouched, which is
# possible only because the overlay is already a separate process.
#
#   py -3.11 -m venv .overlay-venv
#   .overlay-venv/Scripts/python.exe -m pip install PySide6==6.4.3 pyinstaller
#
# Why 6.4.3 specifically: the overlay flickered on every newer release.
# Qt moved QtWebEngine onto the ANGLE backend in 6.5.1 and translucent
# windows have flickered on it since (same symptom reported against
# another Qt WebEngine app, TissUUmaps #47). 6.4.3 predates that switch,
# and the flicker is gone on it - confirmed by watching it, after 6.10.1
# was wrongly reported as fixed off a single clean run.
#
# Do NOT "fix" a flicker by selecting a different graphics backend - it
# was tried, and ANGLE is also what makes the transparency work here:
#   --use-angle=gl      GPU context lost, nothing renders
#   --use-angle=d3d9    fails to start
#   QT_OPENGL=desktop   renders, but the window is opaque
# Escaping ANGLE means losing the transparency the overlay exists for.
#
# Packaging follows the same split: build.py builds the overlay from
# .overlay-venv and the app from this environment, into two bundles.
