# Legacy Windows reference

Diese Dateien stammen aus der früheren Windows-only Implementierung und sind kein unterstützter Runtime-Pfad mehr.

Sie bleiben vorübergehend als Referenz erhalten, während der Linux-native Wayland-Host, das Layer-Shell-Overlay und die Linux-Desktop-Dienste portiert werden. Neue Features dürfen diese Dateien nicht importieren.

Sobald die entsprechenden Linux-Komponenten vollständig ersetzt und getestet sind, kann dieses Verzeichnis entfernt werden. Die Git-Historie bleibt die dauerhafte Referenz.
